# Pre-registered decision rule

Recorded before the v2 paired campaign was executed.

1. Where five-seed paired evidence exists, the five-seed approximation gap,
   Coordination Gain, and buffered ratio supersede the single-seed exploratory
   values for the integrated DCHF classification. This applies to EVERY cell
   with five-seed evidence, not only to cells whose class changes.

2. The capacity-precedence threshold remains BR = 0.10 as pre-specified in
   Section 4.2.4. It will not be adjusted in response to the observed values.

3. If the resulting integrated counts differ from 3 / 3 / 0 / 4 / 20, the new
   counts are adopted and propagated to the abstract, Sections 4.6 and 7.8,
   Table 12, Table 18, Figure 5, and the S-10 reconciliation text.

4. Any change is reported explicitly in the response letter as a consequence of
   completing the multi-seed diagnostics, not silently absorbed.
